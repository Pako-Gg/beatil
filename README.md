# BEATIL — Phase 1

מה שנבנה בשלב הזה: מבנה פרויקט מלא, חיבור למסד נתונים אמיתי (Supabase), הרשמה/התחברות עובדות, בחירת Producer/Artist, Onboarding, ודשבורד בסיסי. עדיין **אין** לך שרת פועל באינטרנט — לשם כך צריך לעבור את הצעדים למטה פעם אחת.

**חשוב:** מסמך זה מיועד לך — לא מתכנת. כל צעד כתוב כפעולה ברורה.

---

## שלב א' — יצירת חשבון Supabase (הבסיס: מסד נתונים + Auth + אחסון קבצים)

1. פתח דפדפן ולך ל: https://supabase.com
2. לחץ **Start your project** → התחבר עם GitHub או Google.
3. לחץ **New project**.
4. תן שם לפרויקט: `beatil`, בחר סיסמה למסד הנתונים (שמור אותה במקום בטוח), ובחר Region קרוב (למשל Frankfurt).
5. לחץ **Create new project** וחכה כ-2 דקות שהוא יוקם.

## שלב ב' — הרצת ה-Database Schema

1. בתפריט השמאלי של Supabase, לחץ על **SQL Editor**.
2. לחץ **New query**.
3. פתח אצלך את הקובץ `supabase/migrations/0001_init_schema.sql`, העתק את כל התוכן, הדבק בעורך ה-SQL, ולחץ **Run**.
4. חזור על אותו תהליך עם הקובץ `supabase/migrations/0002_storage.sql` (query חדש → הדבק → Run).
5. ודא שאין הודעת שגיאה אדומה. אם רץ בהצלחה — מסד הנתונים שלך מוכן.

## שלב ג' — חיבור הפרויקט למפתחות שלך

1. ב-Supabase, לך ל **Project Settings** (גלגל שיניים) → **API**.
2. תמצא שם שני ערכים: **Project URL** ו-**anon public key**.
3. אצלך בפרויקט, שכפל את הקובץ `.env.local.example` לקובץ חדש בשם `.env.local`.
4. הדבק את שני הערכים במקומות המתאימים בקובץ `.env.local`.

## שלב ד' — הרצת הפרויקט במחשב שלך

צריך שיהיה מותקן Node.js (גרסה 18 ומעלה). אם אין לך — הורד מ: https://nodejs.org

לאחר מכן, בטרמינל (או ב-Claude Code, שיכול להריץ את זה בשבילך):

```
npm install
npm run dev
```

פתח דפדפן בכתובת: http://localhost:3000

אתה אמור לראות את דף הבית של BEATIL. נסה להירשם דרך `/signup`.

## Phase 2 — מה נוסף

- **App Shell**: Header + Bottom Nav במובייל, Sidebar בדסקטופ, הכל responsive
- **דף בית מלא**: טרנדים, חדש, מפיקים עולים, מומלץ, סגנונות — עם fallback לתוכן דמו כשה-DB ריק
- **BeatCard** מלא: נגן, לייק, שמירה — מחובר ל-DB האמיתי
- **נגן מוזיקה גלובלי**: Mini Player קבוע בתחתית שמתעדכן בלחיצה על Play מכל מקום באתר
- **חיפוש** עם פילטרים (ז'אנר, מוד, אנרגיה, טווח BPM) מחובר ל-DB
- **פרופיל מפיק ופרופיל אמן** אמיתיים, כולל Follow ו-Message
- **העלאת ביט** מלאה: מעלה קובץ אודיו ותמונה ל-Supabase Storage ושומרת שורה בטבלת beats
- **הודעות**: Inbox + מסך שיחה מלא, כולל unread count
- **התראות**: עמוד עם כל סוגי ההתראות וסימון "נקרא"

### מה לבדוק אחרי שהרצת `npm run dev`

1. פתח `/` — אתה אמור לראות תוכן דמו (עד שיהיו ביטים אמיתיים) עם הודעה כתומה שזה תוכן לדוגמה
2. הירשם כ-Producer, עבור ל-`/upload`, העלה קובץ אודיו קטן — הביט אמור להופיע ב-`/dashboard` וב-`/`
3. לחץ Play על כרטיס ביט — ה-Mini Player למטה אמור להתחיל לנגן ולהישאר בזמן ניווט
4. פתח `/search`, נסה חיפוש טקסט ופילטרים
5. הירשם עם משתמש שני כ-Artist, עבור לפרופיל של המפיק, לחץ Follow ואז Message — ודא שההודעה מגיעה בזמן אמת בין שני החלונות
6. בדוק `/notifications` (יהיה ריק כרגע — ההתראות בפועל ייכתבו אוטומטית בשלב 6, כרגע רק ה-UI מוכן)

### הערה חשובה

עמוד ההתראות מציג נתונים מהטבלה `notifications`, אבל שום דבר עוד לא **כותב** לתוכה אוטומטית (למשל, כשמישהו עושה Follow) — זה מתוכנן ל-Phase 6, יחד עם Likes/Saves/Follow/Feed. כרגע Follow ו-Like כן נשמרים ב-DB, רק ההתראה על כך עוד לא נוצרת.
